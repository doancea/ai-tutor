# INTERVIEW-SCRIPT.md

The literal question text implied by `INTERVIEW-DECISIONS.md` — that doc records *why* each
question exists and its required/optional shape, but not the actual copy anyone (or any
persona) would be asked. This is that instrument. Order follows the group sequence
(A → B → C → D → F; Group E has no question, folded into a standing agent policy). Reviewed and
finalized; not yet run against any persona — that's Step 1 of the grounding plan.

## Group A — Role, goals, and target certification

**Q1 — Role & background**
- Current role / title. *(required)*
- Roughly how many years of professional experience do you have overall? And separately, how
  much experience do you have specifically using Claude or other AI tools, if any? *(required)*
- What industry or domain do you work in? (e.g. consulting, in-house engineering, agency,
  academia, other) *(required)*
- Anything else about how Claude fits into your work today that isn't covered above?
  *(optional, free text)*

**Q2 — Goals** *(required, open-ended)*
What do you want to be able to **do** as a result of this — the actual outcome you're after, not
just a motivation. For example: "design production agent systems for clients," "just want a
structured learning path regardless of the credential," "need this for a role change by a
specific date."

**Q3 — Target certification** *(optional)*
Do you already have a specific Claude certification in mind? Name it if so. If you're not sure,
leave this blank — we'll recommend one from your answers above, and we'll check any named target
against your background too rather than taking it at face value.

## Group B — Tool experience and prior learning

**Q1 — Tool experience** *(required, open-ended)*
Tell us about your hands-on experience with Claude so far — for example, using Claude via chat,
the API/SDK, the Claude Code CLI, MCP, or prompt engineering. Don't worry about covering all of
these evenly; just describe what you've actually done.

**Q2 — Prior structured learning** *(optional, open-ended)*
Have you done any structured learning relevant to this — Anthropic Academy courses, another
vendor's certification (AWS, Gemini, etc.), a bootcamp, self-study, or anything else? Describe
whatever's relevant, even if it isn't Claude-specific.

## Group C — Deadline framing and time budget

**Q1 — Framing** *(required)*
Is there a hard deadline or mandate driving this — a scheduled exam date, an employer
requirement, a role-change effective date? Or is this open-ended and self-paced?
- [ ] Hard deadline / mandate
- [ ] Self-paced / open-ended

*If "hard deadline / mandate" →* required follow-up:
- Target date. *(required)*
- What's driving it? *(required, free text)*

*If "self-paced" →* skip directly to Q2.

**Q2 — Weekly time budget** *(required)*
About how many hours per week can you realistically commit to this?
- [ ] 1–3 hrs/wk
- [ ] 4–7 hrs/wk
- [ ] 8–12 hrs/wk
- [ ] 13–20 hrs/wk
- [ ] 20+ hrs/wk
- [ ] Other: ______

**Q2b — Distribution** *(optional)*
How does that time tend to show up?
- [ ] Mostly daily
- [ ] Mostly weekend / batched
- [ ] Irregular

## Group D — Prior diagnostic

**Q1** *(required)*
Do you have results from an assessment related to this goal (or a similar topic) that you're
willing to share?
- [ ] Yes — I have results to share
- [ ] No
- [ ] No, but I'd be willing to take one

*If "Yes" →* required follow-up: Share your results — paste the raw output if you still have it,
otherwise describe what you remember — and where the assessment was from. *(free text)*

*If "No" or "No, but I'd be willing to take one" →* no further question here — sourcing a viable
existing diagnostic (or, failing that, constructing one) is agent-side behavior, not something
asked of you.

## Group F — Plan format and learning modality

**Q1 — Plan format** *(required)*
How do you want your plan presented?
- [ ] A structured tracker/checklist — phase-by-phase tasks I check off
- [ ] A narrative document — a written guide I read through
- [ ] Loose, high-level guidance — pointers and direction, I'll self-direct on specifics
- [ ] Other: ______

**Q2 — Learning modality** *(optional)*
Do you want to focus more on hands-on practice/building, reading/reference material, or a mix of
both?
- [ ] Hands-on practice / building
- [ ] Reading / reference material
- [ ] Mixed
- [ ] Other: ______

*If "Hands-on" or "Mixed" →* two follow-ups:

**Q2a — Type of hands-on** *(optional)*
What kind of hands-on work appeals to you most?
- [ ] Standalone practice projects / exercises
- [ ] Applying directly to real current work
- [ ] Structured guided labs / tutorials
- [ ] Open-ended tinkering and exploration
- [ ] Other: ______

**Q2b — Size of hands-on tasks** *(optional)*
How big do you want individual hands-on tasks to be?
- [ ] Quick (15–30 min)
- [ ] Medium (1–2 hrs)
- [ ] Large / project-scale (multi-session)
- [ ] Other: ______

*If "Reading/reference" →* skip Q2a/Q2b entirely.
